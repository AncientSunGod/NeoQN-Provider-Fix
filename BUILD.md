# Build NeoQN_Providers_Fixed.apk

1. Create a new GitHub repository and upload the contents of `neoqn-source/`.
2. GitHub Actions will run `.github/workflows/build-fixed-providers.yml`.
3. Download the `NeoQN_Providers_Fixed` artifact from the workflow run.
4. In NeoQN, open Providers and import the resulting APK.

The main NeoQN APK is not modified.
